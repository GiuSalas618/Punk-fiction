# Punk Fiction

A dedicated workspace for developing and writing a work of fiction.

## Project boundary

This repository is the source of truth for the book: its premise, characters, setting, research, outline, drafts, and revision notes. Keep this project separate from IntiPath and Giuliano Salas's business, audience, offers, and other work. Do not import details from those contexts unless Giuliano explicitly asks.

See [AGENTS.md](AGENTS.md) for the writing and context-separation rules.

## Suggested structure

- `00-project/` — premise, themes, questions, and decisions
- `01-world/` — setting, timeline, rules, and research
- `02-characters/` — character profiles and relationships
- `03-outline/` — plot, chapter plans, and scene list
- `04-manuscript/` — chapter drafts
- `05-revisions/` — feedback and revision plans

Start small. Add only the folders that become useful.

## Working method

1. Keep an explicit canon document for facts established in the story.
2. Mark undecided ideas as possibilities; do not silently turn them into canon.
3. Draft in manageable scenes or chapters and preserve earlier versions when a major rewrite matters.
4. Keep research separate from fictional invention, and label uncertain real-world details for verification.

## Privacy

This repository is currently public. Do not put private manuscript material, personal information, or confidential research here unless you intend it to be publicly accessible. Change the repository visibility to private before adding material you want to keep private.
